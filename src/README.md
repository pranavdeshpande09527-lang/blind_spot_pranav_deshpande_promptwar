# Implementation target

The source application is not generated by this prompt-writing task. Keep the existing root index.html as the frontend; do not overwrite it with a starter template.

Suggested backend modules: server.ts, config.ts, routes/, middleware/, repositories/, services/analysis.ts, providers/gemini.ts, providers/groq.ts, providers/tavily.ts and shared/schemas.ts. Add browser modules alongside the existing frontend only as needed. Add executable SQL under supabase/migrations, tests under tests, package scripts and render.yaml during implementation.

Serve only explicit public files/assets, never the whole project directory: .env, prompts and backend source must not be downloadable. Keep browser Supabase session handling separate from server-only provider credentials.
